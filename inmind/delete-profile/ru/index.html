Удаление профиля "1001 задача для счета в уме"

Удалить свой профиль можно непосредственно в приложении.

Для этого в боковом меню приложения выберите пункт "Профиль", затем на экране профиля нажмите на кнопку "Удалить профиль".

По поводу удаления профиля с нами можно связаться по электронной почте: dwerty@yandex.ru.
